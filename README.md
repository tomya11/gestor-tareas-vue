# gestor-tareas-vue

Aplicación de gestión de tareas desarrollada con Vue 3. Permite crear, editar y eliminar tareas con prioridades, estados y fechas de vencimiento, con persistencia en localStorage.

## Funcionalidades

- Crear, editar y eliminar tareas
- Asignar prioridad (alta, media, baja) y estado a cada tarea
- Fechas de vencimiento por tarea
- Modal de edición
- Persistencia en localStorage (las tareas se mantienen al recargar la página)
- Filtro por estado o prioridad

## Tecnologías

- Vue 3 (Composition API)
- Vue Router
- Composables
- localStorage
- HTML5 / CSS3
